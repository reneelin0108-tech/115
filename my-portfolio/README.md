# 台灣 SEO 行銷網站

包含首頁、公司介紹、聯絡我們與送出成功頁面，可部署到 GitHub Pages。

## 檔案
- `index.html`：首頁
- `about.html`：公司介紹
- `contact.html`：聯絡表單
- `thank-you.html`：表單送出後的感謝頁
- `style.css`：共用樣式

## 上線前必做
1. 開啟 `contact.html`，將 `YOUR_EMAIL@example.com` 改成要收取表單的電子郵件。
2. 將 `_next` 的 `YOUR-GITHUB-USERNAME` 改成 GitHub 帳號，`YOUR-REPOSITORY` 改成 Repository 名稱。
3. 使用 FormSubmit 首次送出驗證信箱，並完成信箱啟用。
4. 將所有檔案放在 GitHub Repository 根目錄，並在 Settings → Pages 啟用 `main` 分支的 `/ (root)`。

注意：表單寄信由 FormSubmit 第三方服務處理；需完成其信箱驗證，實際收信功能才會啟用。請先用自己的測試資料測試，不要提交他人的個人資料。
